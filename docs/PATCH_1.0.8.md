# Lupin 1.0.8

Steadier inventory and shop prices, plus the November Classic World database update.

- Inventory prices stay attached while tabs flash and the orange new-item outline blinks, including when both animate together.
- Shop price labels fade where they cover the add-item window. Lupin can recognize the form at first opening even when labels partly cover it.
- Price cards transition smoothly when hovered items appear or disappear, without the white flash in Prices.
- Database includes Forgotten Hollow’s maps, monsters, quests, weapons, furniture and verified shop items. Mano and Stumpy’s Black Sacks list the Companion’s Magic Box from Kerning City Party Quest as their reported source.

### Install or update

Use **Settings → Check now** in Lupin, then **Download & install**, or download the package for your system below.

- **Windows** — run `Lupin-1.0.8-Windows-x64-Setup.exe`.
- **Arch/Manjaro** — `sudo pacman -U ./lupin-1.0.8-1-x86_64.pkg.tar.zst`
- **Debian/Ubuntu** — `sudo apt install ./lupin_1.0.8-1_amd64.deb`

After updating, select **Start reading** to reconnect your display. Both local translation models are included.

Checksums, signed update metadata, build information, and [release verification](https://github.com/zhuffman68/lupin/releases/download/v1.0.8/VERIFICATION-1.0.8.md) accompany the packages.
