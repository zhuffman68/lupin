# Lupin 1.0.7

Find your way around with interactive portals, track rapid meso pickups more reliably, and browse steadier price cards.

- **Find portal** in Database → Maps highlights numbered entrances and brings them into view. Hover a pin for its destination, click to open it, and use Back to return to your view.
- Meso tracking catches more short-lived pickup messages during bursts. Tracking can also recover after losing sight of Classic World while it waits for readable EXP digits.
- Inventory prices handle long scroll names and more equipment comparison layouts, including descriptions against the bottom edge.
- Item names and prices stay steady when switching detail tabs. Shop cards and **Where seen** results update smoothly as rows change. Removed the item count line above on-screen prices.

### Install or update

Use **Settings → Check now** in Lupin, then **Download & install**, or download the package for your system below.

- **Windows** — run `Lupin-1.0.7-Windows-x64-Setup.exe`.
- **Arch/Manjaro** — `sudo pacman -U ./lupin-1.0.7-1-x86_64.pkg.tar.zst`
- **Debian/Ubuntu** — `sudo apt install ./lupin_1.0.7-1_amd64.deb`

After updating, select **Start reading** to reconnect your display. Start a new tracking session from **EXP/Meso Tracking**. Both local translation models are included.

Checksums, signed update metadata, build information, and [release verification](https://github.com/zhuffman68/lupin/releases/download/v1.0.7/VERIFICATION-1.0.7.md) accompany the packages.
